# Animated five-bar chart

A Remotion animation with five bars, progressive counters, and a dark background.

**[Download and watch the MP4](animated-chart/out/five-bars.mp4)** — Full HD, 30 fps, 6 seconds. Open the file and click **View raw** or **Download raw file** to watch it.

## Run the project

```sh
cd animated-chart
npm ci
npm run dev
```

Select `FiveBars` in Remotion Studio. See [project instructions](animated-chart/README.md) for editing and validation.
